# BEENTEUM 혼잡도 계산 PoC

## 1. 프로젝트 개요

빈틈(BEENTEUM)에서 사용자가 제보한 혼잡도 정보를 이용해 카페의 현재 혼잡도를 계산하는 기능을 구현한 PoC입니다.

카페별로 들어온 제보 중 최근 60분 이내의 데이터를 확인하고, `여유 / 보통 / 혼잡` 각각의 제보 개수를 비교하여 가장 많이 나온 상태를 현재 혼잡도로 표시합니다.

제보가 부족하거나 두 개 이상의 상태가 같은 횟수로 나온 경우에는 임의로 혼잡도를 정하지 않고 `정보 부족`으로 표시합니다.

---

## 2. 개발 환경

- Java 17
- JUnit 5
- Maven
- PostgreSQL

---

## 3. 혼잡도 계산 기준

현재 혼잡도는 최근에 들어온 제보를 기준으로 계산합니다.

| 항목 | 적용 기준 |
|---|---|
| 제보 확인 범위 | 최근 60분 이내 |
| 혼잡도 상태 | 여유 / 보통 / 혼잡 |
| 최소 제보 수 | 2건 |
| 제보가 없는 경우 | 정보 부족 |
| 제보가 2건 미만인 경우 | 정보 부족 |
| 가장 많이 나온 상태 | 현재 혼잡도로 표시 |
| 최다 상태가 동점인 경우 | 정보 부족 |
| 오래된 제보 | 현재 혼잡도 계산에서 제외 |

제보 수가 너무 적은 상태에서 혼잡도를 정하면 실제 상황과 다를 수 있기 때문에, PoC에서는 유효한 제보가 **2건 이상일 때** 혼잡도를 계산하도록 정했습니다.

## 4. 혼잡도 계산 과정

```text
카페 제보 확인
      ↓
해당 카페의 제보만 확인
      ↓
최근 60분 이내 제보 필터링
      ↓
유효한 제보가 2건 이상인가?
      ↓
   ┌── 아니오 ──→ 정보 부족
   │
   예
   ↓
여유 / 보통 / 혼잡 개수 확인
      ↓
가장 많이 나온 상태 확인
      ↓
동점인가?
   ├── 예 → 정보 부족
   │
   └── 아니오
        ↓
현재 혼잡도로 표시
